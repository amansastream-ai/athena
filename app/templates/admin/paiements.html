Procédure d'activation

1Wave : ouvrir un compte Wave Business (KYB : RCCM, NINEA, pièce d'identité), générer une clé API et un secret webhook, déclarer l'URL HTTPS /webhooks/wave, tester en sandbox puis activer wave_checkout_enabled.
2Orange Money : signer le contrat marchand Web Payment auprès de Sonatel, récupérer les URLs d'API Senegal sur le portail, renseigner OM_TOKEN_URL, OM_WEBPAYMENT_URL, OM_STATUS_URL, le secret de callback, puis tester.
3Multi-vendeurs : utiliser l'API Aggregated Merchants de Wave pour attribuer chaque encaissement au sous-marchand, ou encaisser sur le compte plateforme et reverser via l'API Payout.
4Alternative : un agrégateur agréé (PayDunya, CinetPay, etc.) peut couvrir Wave + Orange + Free + cartes avec une seule API — à évaluer contractuellement et techniquement.
